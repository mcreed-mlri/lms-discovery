# Scenario images

Drop photographs here. Missing files fall back to a gradient, so the
scenario stays usable before the art arrives.

Expected by the eviction scenario (app/demo/scenario/page.tsx):

| File               | Storyboard frame | Suggested subject                       |
| ------------------ | ---------------- | --------------------------------------- |
| `desk-morning.jpg` | 01 (opening)     | Desk, lamp, folders, mug. Warm morning. |
| `desk-evening.jpg` | 09 (closing)     | Same desk, softer end-of-day light.     |

Guidance:

- 1600x900 or larger, landscape. They render full-bleed and are cropped
  with `object-cover`.
- **Avoid identifiable people.** The Unsplash licence does not convey model
  releases, and depicting a real person as a client carries real risk for a
  legal aid organisation. Desks, documents, and interiors are safe.
- Text sits over a dark scrim on the left (opening) or centre (closing), so
  pick images whose detail is not concentrated there.
