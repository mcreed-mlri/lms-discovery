# Legal Skills: Hearsay Prototype

Standalone Brightspace-ready LACE course package for the demo.

This folder was copied from `Course-Template` so the reusable template stays
untouched. It uses the same static architecture:

- `course-config.js` is the source of truth for the five subskills, navigation,
  drawer, prev/next links, and local progress.
- `Home.html` shows the module outline and demo learning pattern.
- `Modules.html` shows a visual map of the five-subskill structure.
- `defending-hearsay-objection-writing.html` is the complete interactive
  prototype for Subskill 2.
- The other four subskill pages are planned-state shells for module context.
- `course-style.css`, `course-nav.js`, and `course-beacon.js` are copied from
  the established LACE course template.

## Prototype Scope

The built subskill demonstrates:

1. Review Key Concepts
2. Watch an Expert Model
3. Supported Practice
4. Rapid Practice
5. Review the Procedure
6. Independent Practice

Persistent resources include Key Concepts and Procedure Reference panels.

## Content Status

Legal doctrine, authority placeholders, sample analyses, and drafting language
are prototype content. They must be reviewed by a legal subject-matter expert
before learner-facing production use.

## Local Preview

Open `Home.html` in a browser. The package is static and does not require a
backend, database, npm install, or build step.
